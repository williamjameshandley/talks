# Bayesian Techniques for GNSS-R

## Abstract

An introduction to Bayesian inference for inverse problems, aimed at PhD students in GNSS reflectometry and satellite remote sensing. The talk covers the journey from least-squares fitting to full Bayesian parameter estimation and model comparison using nested sampling, illustrated with line fitting, gravitational wave localisation, and satellite orbit determination. A second section introduces AI-augmented scientific workflows, and a third introduces GPU-native nested sampling in BlackJAX and Charlotte Priestley's differentiable SGP4 propagator (jaxsgp4), leading into a hands-on workshop session.
