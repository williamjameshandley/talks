# AI/ML Tools for Research

## GAMBIT LLMBit Workshop - December 2025

A practical workshop on AI/ML tools for research, covering the current landscape as of December 2025.

### Key Topics

- **Three layers of AI tools**: Autocomplete, Chat-based AI, Agentic Systems
- **Current model landscape**: GPT-5.2, Claude 4.5 Opus, Gemini 3
- **Agentic tools**: Claude Code (best in class), Gemini CLI, Codex
- **Context Engineering**: The shift from prompt engineering moving into 2026
- **Cost considerations**: Free models for chat, subscriptions for agents
