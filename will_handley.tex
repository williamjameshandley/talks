\begin{frame}
    \frametitle{First things first}
    If you've been busy, the landscape has shifted massively in late 2025.
    \vspace{0.5cm}
    \begin{itemize}
        \item \textbf{February 2025}: Models acquired PhD-student capabilities (o3, Gemini 2.5, Claude 3.5).
        \item \textbf{May 2025}: Agentic systems (Claude Code, Cursor) moved us from ``chatting'' to ``doing.''
        \item \textbf{November 2025}: The heavyweights arrived.
            \begin{itemize}
                \item \textbf{Gemini 3, GPT-5.1, Claude 4.5 Opus}.
                \item Massive context windows and ``slow thinking'' defaults.
            \end{itemize}
        \item \textbf{December 2025}:
            \begin{itemize}
                \item \textbf{GPT-5.2}: OpenAI's counter to Gemini 3.
                \item \textbf{Codex returns}: Re-launched as a dedicated agentic coding model.
            \end{itemize}
        \item \textbf{The new performance gap}:
            \begin{itemize}
                \item \textit{Chat:} The gap has closed. Free models are now excellent.
                \item \textit{Agents:} ``You get what you pay for.'' Free agents loop; paid agents finish.
            \end{itemize}
    \end{itemize}
\end{frame}

\begin{frame}
    \frametitle{On AI Hype}
    \begin{columns}
        \column{0.48\textwidth}
        \begin{itemize}
            \item These things are not ``intelligent'' in the way Silicon Valley wants you to believe (AGI is not just around the corner).
            \item \emph{Caveat emptor}: It is very hard for a human to read language, and not reflexively construct a mind behind it.
            \item You should not however think of them as mere ``next token predictors'':
                \begin{itemize}
                    \item The modern reinforcement learnt reasoning systems are significantly more than that.
                    \item Agentic tools ground these in reality.
                \end{itemize}
        \end{itemize}
        
        \column{0.48\textwidth}
        \begin{block}{A senior examiner's experiment}
            \begin{itemize}
                \item I got o3 to take the Part II exams.
                \item Prompt on exam day: ``You are a first class Part II Cambridge astronomy student... here is the syllabus... here is the question, answer it''.
                \item Toby Lovick transcribed answers onto written exam scripts.
                \item Slipped them amongst real scripts and marked blind.
                \item \textbf{Result}: Best student we've had across IoA history, even without coursework.
            \end{itemize}
        \end{block}
    \end{columns}
\end{frame}

\begin{frame}
    \frametitle{Layer 2: Cost}
    \framesubtitle{Pay as you use vs subscription models}
    
    \begin{columns}
        \column{0.6\textwidth}
        \begin{itemize}
            \item Gemini is free to use (but you sign away your data).
            \item ChatGPT and Claude offer \$20/month subscriptions.
            \item API access available: pay per token consumed:
                \begin{itemize}
                    \item \$0.0002-0.015 per 1000 tokens (roughly 750 words).
                    \item Orders of magnitude cheaper for research use.
                    \item Only pay for what you actually use.
                \end{itemize}
            \item Never buy yearly subscriptions - AI evolves too rapidly.
            \item My group's preference: pay for API access via tokens.
                \begin{itemize}
                    \item Pay for what you use.
                    \item Allows you to try out the latest models.
                    \item API keys allow you to do all kinds of tricks at the command line.
                \end{itemize}
        \end{itemize}

\begin{frame}
    \frametitle{The Economics of Agents}
    \framesubtitle{``You get what you pay for''}

    \begin{itemize}
        \item \textbf{Chat is cheap, action is expensive.}
        \item While Gemini 3 and GPT-5.1 have free tiers for chat, their \emph{agentic} capabilities are severely throttled.
        \item \textbf{Why pay?}
            \begin{itemize}
                \item \textbf{Context:} Agents need to read your whole repo (100k+ tokens) every prompt.
                \item \textbf{Rate limits:} Free tiers hit limits after 5--10 agent steps. Complex refactors need 50+.
                \item \textbf{Reliability:} Paid models (Opus 4.5/Codex) self-correct. Free models get stuck in loops.
            \end{itemize}
        \item \textbf{Recommendation:} If you are using agents, you need the \$20/mo subscription or an API budget.
        \item There are many further unknown costs of shifting your research toward ``hands-free coding''.
    \end{itemize}
\end{frame}
