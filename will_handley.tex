    \framesubtitle{Distinct shifts, often conflated}

        \column{0.48\textwidth}
        \begin{block}{\C[0]{Revolution 1: GPUs for Science}}
            \begin{itemize}

                \item Speedups of $100\times$--$5000\times$
                \item Rigorous Bayesian inference at previously impractical scales
            \end{itemize}
        \end{block}
        \column{0.48\textwidth}
        \begin{block}{\C[3]{Revolution 2: LLMs for Scientists}}
            \begin{itemize}
                \item Large Language Models change how we write code and manage research
                \item Not automating the science itself
                \item Reducing the technical overhead (verification is the new bottleneck)
            \end{itemize}
        \end{block}
    \end{columns}

        Classical methods on GPUs are scientifically profound. LLMs are what make building them possible.

\begin{frame}
    \frametitle{Definitions}
    \framesubtitle{What do we mean by ``Classical Methods''?}
    \begin{block}{Classical Inference}
        Algorithms that converge mathematically to the true posterior (MCMC, Nested Sampling, HMC). They produce triangle plots, error bars, and \textbf{full Bayesian model comparisons}.
    \end{block}
    \vspace{1em}
    \begin{block}{The Flagship Challenge}
        \begin{itemize}
            \item \textbf{JWST/Euclid/LSST}: Unprecedented data volume requires automated, robust systematics handling.
            \item \textbf{SKA/LIGO}: Real-time requirements ($<1$ minute) for transient localization.
            \item \textbf{The Gap}: We have the instruments. Classical methods on GPU hardware can match or outperform neural network approaches --- and they're interpretable.
        \end{itemize}
    \end{block}
\end{frame}

\begin{frame}
    \frametitle{What Speed Bought Us}
    \framesubtitle{Marginalising latent variables at scale}
    \student{toby_lovick.jpg}{Toby Lovick}{PhD Student}
    \begin{columns}
        \column{0.5\textwidth}
        \begin{block}{Laplace Approximation + Optimisation}
            \begin{itemize}
                \item SNe have 100s of latent variables per object (beyond SALT2's 2).
                \item LAO: optimise to mode, auto-diff the Hessian, marginalise exactly.
                \item \textbf{25,602-D} likelihood in \textbf{11 minutes}.
            \end{itemize}
        \end{block}
        \begin{block}{Why This Matters}
            \begin{itemize}
                \item Nested Sampling at this scale: $D^3$ $\to$ a decade of H200 time.
                \item Planck needed manual per-parameter derivations. LAO just auto-diffs the forward model.
            \end{itemize}
        \end{block}
        \column{0.5\textwidth}
        \includegraphics[width=\textwidth]{figures/toby-lao-scaling.pdf}

    \frametitle{Summary}
    \begin{enumerate}

        \item \textbf{The Result}: We can tackle systematics and model complexity that were previously impossible.
