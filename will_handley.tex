\begin{frame}{What is an agent? ChatGPT that can edit and run your code}
    \begin{columns}[T,onlytextwidth]
        \begin{column}{0.48\textwidth}
            If you get too skilled at chat-based AI, you become a
            \keyterm{copy-paste-run-debug monkey}.
        \end{column}
        \begin{column}{0.48\textwidth}
            Agentic systems are what happens if you let ChatGPT
            \keyterm{edit files, run commands, and inspect the behaviour}.
        \end{column}
    \end{columns}
    \bigskip
    {\small
    \figurerequest[minimum height=2.7cm]{Will: paired diagrams, aligned with
    the columns above. Left: ChatGPT $\leftrightarrow$ scientist
    $\leftrightarrow$ editor/terminal; code copied out, errors copied back.
    Right: scientist gives the task; ChatGPT edits a file, runs it, reads
    the output and revises the file in a loop. Keep the scientist visible
    directing and inspecting the work. Use the same file and error in both.}}
    \bigskip

    This closes the scientific loop.
    \smallskip

    Agentic systems are (partially) grounded in reality. Correctly guided,
    they can reduce hallucinations by testing their hypotheses.
\end{frame}
